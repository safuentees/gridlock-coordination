## Accepted-schema proposal

- **Identity/unit:** native Project ID unchanged, internal ID `carolinas-tpc:<Project ID>`, identityBasis native-id, recordUnit project. One published row remains one project even when it names multiple lines, voltage levels or terminals. Preserve native IDs independently of edition; no invented parent program or aliases.
- **Status:** update pp.13/16/17 footnote 1 defines Underway as a range from current-year budget provision through some construction. Map both Underway and Planned conservatively to lifecycle planned while preserving raw status; never infer under-construction. Conceptual explicitly means not planned: planning-context/unknown. Retain 89 planned and nine unknown context observations. Exclude operational In-Service and Removed rows, with exact reasons in the ledger.
- **Owner:** update tables explicitly label Transmission Owner. Final-plan **PDF p.52 / printed p.50, field 4** defines this as the responsible equipment owner designated to design and implement the project. **PDF p.3 / printed p.1** expands DEC to Duke Energy Carolinas, LLC and DEP to Duke Energy Progress, LLC. Source-scoped IDs `carolinas-tpc-dec` / `carolinas-tpc-dep` are supported, with row evidence plus these definitions. Composite DEC/DEP remains sponsor text and null owner; no split record. No global owner registry, common-parent equivalence or cross-source distinction is established.
- **Dates:** the exact normalization evidence is the update's **p.1 opening paragraph**, not a status footnote: June 1 and December 1 represent the peak season by which service is expected, with actual dates used where applicable. These are not exact estimated days. Preserve raw text and seasonal label, normalize June1/December1 to the displayed **year**, kind in-service. The final-plan **PDF p.19 / printed p.17** explicitly pairs summer 2030 with winter 2030/2031 (and 2035 with 2035/2036): winter crosses calendar years. A displayed December 2031 target therefore stays year 2031 with its raw winter-season label; neither shift it to 2032 nor claim that the whole winter ends in 2031. Non-placeholder E200161 `6/30/2026` remains a reported estimated day despite its still-Underway status. TBD becomes unknown. No forecast proves completion; no construction windows.
- **Location/voltage/cost:** selected tables supply facility/endpoint names in project text but no native coordinates, per-row state field, CRS or precision. Keep sourceState/sourceLocation null unless a distinct source field is later approved; retain names in description. All locations/nativeGeometry null, centerRole unknown. Extract only explicit kV values from the named scope; absent values stay empty. Preserve estimated nominal-dollar cost as labeled source notes, not benefit: footnote 2 includes direct costs/loadings/overheads but excludes AFUDC; p.1 describes rounding. A dash is unknown, never zero.
