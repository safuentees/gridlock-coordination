Continue with reusable high-volume source GIS/facility matches across the unresolved collection; preserve ambiguity and failed outcomes where no suitable data exists. Record source, CRS, permitted use, hash and transformation; do not invent accuracy or project centers. Use only B paths in the parent contract.
