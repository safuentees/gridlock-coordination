# F28-B — Reusable geographic references

Produce versioned reusable reference assets from permitted public official GIS/facility and administrative sources. Prioritize complete reference coverage applicable to large imported inventories (PJM/MISO/ERCOT/SPP/PG&E), not a new small research sample. First connect complete state/territory bounding extents and accepted BPA exact-ID pins, then add facility/county/town references and source adapters by expected usable coverage. Record exact source/CRS/use/hash/transformation; no invented accuracy or project centers. Use only B paths in the parent contract.

Dependencies, owner, exact file boundaries and observable acceptance are fixed in [the parent spec](spec.md). Coordinator owns shared changes and sole bounded checks.
