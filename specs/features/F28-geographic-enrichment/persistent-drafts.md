# F28-R2 — Return to unfinished geographic reviews

Purpose: an analyst correcting many records can return after reload without losing unfinished cited evidence. Review/correction/restore remain separate from source records; saved drafts are not accepted decisions or map locations. Depends on R's dirty-draft baseline contract and separate mode storage. Shared `domain/geographic-drafts.ts` is committed before parallel core/UI work.

Core owns only new `app/src/data/geography-drafts.ts` and `changes/F28-persistent-drafts-core.md`. Export `readGeographicDrafts(mode): Promise<{session: GeographicDraftSession | null; error: string | null; writeBlocked: boolean}>`, `saveGeographicDrafts(session, writeBlocked?: boolean): Promise<string | null>`, and `downloadGeographicDrafts(session): void`. Use a separate versioned IndexedDB database/store, mode key, schema/identity/mode checks, serialized writes and 80 MiB bound. Malformed existing data blocks overwrite and is preserved; unavailable storage keeps in-memory work exportable. No localStorage migration, source/run/review-store mutation or private external transmission. No worker checks.

UI owns only `GeographyPanel.tsx`, optional new `features/readiness/use-geographic-drafts.ts`, and `changes/F28-persistent-drafts-ui.md`. Replace its private raw ReviewDraft interface with the frozen type. Restore both modes' dirty drafts/baselines once before automatic writes. Prefer newer in-session dirty work if restoration arrives after edits; do not overwrite it. Persist only actual dirty drafts after a short debounce, retaining absent source IDs and original fingerprints. A changed/returned source keeps the old draft with the existing explicit re-review guard. Successful review/discard removes its dirty stored entry; merely opening Review saves no draft. Keep pending drafts protected from companion-review import.

Show concise browser-storage/error/recovery state only when useful, with Download drafts when saving fails. Never announce a draft as an accepted review. Draft storage operates independently of collection processing and completed decisions; mode switching/reload cannot mix source/demo drafts. Keep in-memory and remote worker changes intact. Root owns integration and the sole later bounded compile/representative restore case.

Completion: partial blank fields survive reload with source identity/baseline intact, cross-mode/changed-source conflicts are guarded, removed records keep their unfinished drafts, malformed prior saves are preserved, and active reviewed geometry never changes merely from draft restoration.
