Restore them as unfinished work with a preview; never apply reviewed geography, original Dataset data or strict calculations. Clean incoming entries are duplicates/no work. Apply rejects a changed base or source snapshot, recomputes the plan and adds only restore/restore-stale/retain-absent entries. Preserve original fields, baselines, times, existing decisions and input objects. No persistence side effects or calculation/pipeline edits. No worker checks.

Retain full-collection navigation, drafts, source/demo boundaries, shadcn defaults and internal scrolling. Root remains merge/check owner.
