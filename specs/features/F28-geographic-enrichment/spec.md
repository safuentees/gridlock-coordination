## Frozen first-connection API

`app/src/enrichment/index.ts` exports:
- `PIPELINE_VERSION: string`, `extractGeographicClues(project: Project): GeographicClue[]`.
- `enrichCollection(dataset: Dataset, references: GeographicReferenceBundle, options?: { previous?: GeographicRun | null; onProgress?: (processed: number, total: number) => void }): Promise<GeographicRun>`.
- `geographicCoverage(run: GeographicRun | null, projects: Project[]): Record<GeographicStatus, number>`; missing rows count not-processed. No counting stale/foreign IDs as current.

Use the committed domain types exactly. SHA-256 source fingerprints compare all Project fields except notes (analyst notes) and recursively canonicalize object keys, retaining array order. An old run can only reuse matching IDs/fingerprints in the same mode and with the same referenceRevision/pipelineVersion. Cache unsupported/ambiguous results too. Preserve prior review metadata on changed inputs, flag stale review in the outcome reason, and never silently overwrite the reviewed representation. Yield periodically so processing thousands of records does not freeze controls. No network calls in runtime matching; producers supply versioned local reference snapshots. Resolve source locations first, honoring method/confidence/role. An unknown/general-pin/permit-area source location is approximate, not a qualified center. Native exact coordinates stay exact; numeric accuracy stays unknown unless native evidence states it.

Reference matching: projectIds are exact allowlists for curated native evidence (BPA), sourceKeys optionally constrain inventory, stateCodes constrain name matching. Exact normalized facility/endpoint names require consistent state/source context and uniqueness; multiple candidates remain ambiguous. Do not reuse name matches across incompatible source identities. Extract explicit states without treating source publisher's footprint as a project state; multiple states should remain multiple clues. Area references provide bounding extents only. Prefer supported narrower geography; fallback area may remain useful while unresolved finer identity is described in the reason. Do not fabricate endpoints from a single compound name; only explicitly parsed endpoints plus separately matched references support an endpoint estimate. No midpoint is necessary for the first connection.

`GeographyPanel` props: `{ dataset: Dataset; run: GeographicRun | null; busy: boolean; progress: {processed:number;total:number} | null; error: string | null; onProcess: () => void; onDownload: () => void; onExploreProject: (id:string) => void }`. UI imports coverage from enrichment. Root provides automatic processing/controller/cache and places this panel in a meaningful Readiness alternate view, keeping the existing evidence editor mounted. No persistent UI state owned in the pipeline. Disable unavailable actions appropriately; keep errors actionable and concise. Initial panel does not claim map integration until M ships.

GeographicRun is a versioned companion, not a Dataset import or automatic Project.location rewrite. Its separate storage/export preserves original records and existing 80 MiB Dataset limit. Review metadata is part of the companion contract now; richer correction interactions deliver in R. Reference source access must permit intended use; cache/public snapshots retain citations, hashes, use constraints and retrieval date. Respect rate limits; don't use public geocoders as unrestricted bulk APIs. No private/restricted/CEII sources, access bypass, paid services or contact-form submissions without applicable authorization.
