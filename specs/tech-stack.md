## Field meaning
- `id` is stable source-based identity, `sourceId` native project ID, `utilityId` reporting/filing group (`desc` or `gpc`), `sponsor` separately preserves listed owner/sponsor or null. Reporting-group comparison does not guarantee different asset owners.
- `date.value` ISO source date with explicit precision and kind (`in-service`, `need`, `unknown`); partial values retain precision, not invented day precision. `buildWindow` is null unless actual construction bounds are known.
- `location` is null when unknown; decimal WGS84 lat/lon, method and confidence accompany evidence. Midpoint means arithmetic endpoint average per guide. `unverified` includes workbook-provided coordinates; no invented precision or independently verified claim.
- Distances in statute miles, voltage in kV, time gap absolute UTC calendar days only when both dates have day precision. Geometry uses project centers, never inferred full corridors. Strict distance < radius. Default 25 mi; maxDateGapDays null means no timing exclusion. Unknown dates fail an explicitly enabled date-gap filter and otherwise remain candidates.
- Distance is primary rank, then known date gap, then stable ID. Construction overlap only when explicit windows intersect. Date proximity is milestone context, never proof of simultaneous construction. Date-proximity default <=365 days is a reversible convention.
- SourceRef uses exact filename and page/sheet/range; optional URL only when known. Missing cost, dates, sponsor or location are null. `notes` retain material caveats.
- Dataset includes mode, version, snapshot title/date and processed/skipped/failed counts. Real counts exclude synthetic records. Export demo labels. Treat imported text as plain data.

F27 source-session APIs are asynchronous and store complete validated revisions in IndexedDB (`gridlock.source-revisions.v1`, store `revisions`, key `active`). Valid legacy `gridlock.source-session.v1` localStorage data is read when no primary revision exists and is preserved until explicit reset. Malformed data blocks writes; unavailable persistence leaves the active session available for download. App waits for initial restoration, retains mounted views during writes and guards stale completions. Source imports allow 80 MiB for the measured 73,880,891-byte formatted California/Carolinas aggregate; PG&E's full source is 13,676,455 bytes, exceeding the qualification estimate and the prior aggregate's 64 MiB guard. Import UI derives its limit from the constant. Keep this bounded rather than silently dropping records. Brief restoration keeps its independent 10 MiB limit. No backend or saved-review storage migration.

F27-L1 changes bundled loading to `loadDataset(mode): Promise<Dataset>`, cached per mode with rejected attempts evicted. Coordinator's `data/real/provider.ts` is the authoritative ordered source composition: static asset URLs are loaded as JSON and passed through the existing schemas/composition, not compiled into the initial script. `data/demo/provider.ts` lazily constructs the unchanged fixtures. UI temporarily owns App's loading/retry/mode-switch consumer under the [exact contract](features/F27-us-regional-expansion/deferred-loading/spec.md), preserving active revisions and mounted state while pending. Future source connections edit only the real provider's URL list. No data, calculation, storage-schema or dependency change.
