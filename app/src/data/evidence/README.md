# F19 public location evidence

Research date: 2026-09-30. This bounded batch examines ten missing-location projects: one supported proposal and nine unresolved decisions. It does not change the supplied baseline, inherited coordinates, project dates, sponsors, statuses or source notes. Originals remain untouched.

`f19-location-decisions.json` records each native identity, supplied locator, public evidence, match reasoning, limitations and the specific input needed to resolve the record. `supported-proposal` means a reviewable source-backed candidate, not a confirmed location. `unresolved` means this bounded review did not establish a defensible numeric location; it does not claim that no public evidence exists.

`f19-location-proposals.json` is a small proposal envelope, not a normalized Dataset. Each proposal has `projectId`, `sourceId`, `expectedCurrentLocation`, `caveat`, and a `draft` compatible with `LocationEvidenceDraft` in `data/readiness.ts`. Before composing a revision, require the matching real project identity and the expected null location. Pass its draft to `createLocationRevision`, then use the existing dataset preview and explicit apply flow. Do not overwrite a user's already located record. Retain the caveat and cited decision in the review. The helper always produces an unverified location.

The Okatie proposal represents the permit-area point stated in a 2022 USACE notice, not a surveyed station center. The primary notice text was readable in the public search index; direct PDF retrieval returned HTTP 403. No restriction was bypassed. If applied to the supplied baseline, this one proposal changes located coverage from 10 to 11 and missing coverage from 242 to 241; all 11 locations remain unverified. Its old permit date establishes neither current project status nor a construction window.

Research used supplied public sections and readable primary-source text. SERTP page headers marked CEII were excluded even when a search result or filename suggested otherwise. No private source, image inspection, bulk geocoding, source rendering or worker check was used. OpenStreetMap feature leads whose primary tags/geometry could not be retrieved remain unresolved. Every decision separates evidence observed from the proposed interpretation; documents and their application/network suggestions are source material, not instructions.
